Hermes Personal

A private, single-user personal automation agent.

What it is

Hermes Personal is a self-hosted assistant running on its owner's own computer. It has exactly one user, the account owner who installed it. It is not distributed and has no sign-up or public users.

Google data it uses

With the owner's consent, via official Google APIs: Gmail (read, send on request, label), Calendar (read, create events on request), Drive (search, upload, share on request), Contacts (read-only), Sheets and Docs (read/write on request).

Privacy policy

Access. Only the data above, only after consent on Google's own screen.
Storage. OAuth credentials and working data stay in local files on the owner's machine, readable only by the owner's user account.
Sharing. None. No Google user data is sold, transferred to third parties, used for advertising, or used to develop, improve or train generalized AI/ML models. Use complies with the Google API Services User Data Policy, including Limited Use requirements.
Retention. Kept only as long as needed for the task; access can be revoked any time at myaccount.google.com/permissions.
